Live Project GitHub Repository (Client)

Description

Hero Apps is a React web application that lets users explore a variety of apps, view detailed information about each one, and install them with a single click. It delivers an app-store-like experience in the browser with a gradient-based UI and smooth navigation transitions.

Main Technology Stack

ReactReact RouterTailwind CSSDaisyUIRechartsReact ToastifyReact IconsReact Loader SpinnerLocal Storage API

Key Features

  • App exploration: browse a catalog of apps.
  • App details: view detailed information for each app, with Recharts for data visualization.
  • One-click install: install an app with a single click, with toast feedback.
  • Persistence: Local Storage keeps data in the browser.
  • Polished UI: gradient-based design, loading spinners, and smooth transitions.

How It Works

  1. 1. Explore
    Users browse the app catalog.
  2. 2. Details
    Users open an app to read its detailed information.
  3. 3. Install
    One click installs the app and shows a confirmation.
  4. 4. Return
    Users navigate back with React Router transitions.

A frontend-only React application. React Router handles navigation, Tailwind CSS and DaisyUI handle styling, and the browser's Local Storage API stores data on the client. Run it with npm install and npm run dev.

Challenges Faced

  • Responsive grids: designing complex layouts that adapt to all screen sizes.
  • Pixel-perfect UI: keeping spacing and hover interactions consistent.
  • Card alignment: keeping cards aligned while content renders dynamically.

Potential Improvements & Future Plans

  • User accounts: authentication and personalized dashboards for managing apps.
  • Full-stack transition: convert it into a MERN application with a database and real-time data.
