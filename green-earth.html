Green Earth

Project Links

Live Project GitHub Repository (Client)

Description

Green Earth is a sustainability-focused web application that promotes environmental awareness and eco-friendly practices. Users browse plants by category, open detailed information, and add or remove items from a cart through a clean, responsive interface.

Main Technology Stack

HTML5Tailwind CSSJavaScript

Key Features

  • Dynamic filtering: browse plants by multiple categories.
  • Plant detail modal: structured information for each plant.
  • Cart: add and remove plants from the cart.
  • Responsive UI: a clean layout across devices.

How It Works

  1. 1. Browse
    Users view plants and filter by category.
  2. 2. Inspect
    A modal shows structured details for the selected plant.
  3. 3. Add to cart
    Users add plants to the cart.
  4. 4. Manage
    Users remove plants from the cart as needed.

A frontend-only project built with plain HTML, Tailwind CSS, and JavaScript. There is no build step: open index.html in a browser to run it.

Challenges Faced

  • Responsive grids: designing layouts that fit different content types and screen sizes.
  • Animation performance: adding smooth scroll effects without hurting performance.
  • Consistent spacing: keeping UI spacing consistent across breakpoints.

Potential Improvements & Future Plans

  • Eco-footprint calculator: an interactive calculator for users.
  • Community forum: a space to share sustainable living tips.
  • Backend and accounts: move to a MERN stack with a database and authentication.
